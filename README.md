# Из плуга в параллель — учебная модель Riders School

Интерактивная модель поворота начального уровня: поворот начинается в плуге, а в выбранном месте
внутренняя лыжа встаёт параллельно, и дальше обе лыжи режут дугу на канте.

**Открыть:** https://antonio-rider-code.github.io/riders-plough-to-parallel/

- Где закрыть плуг и как резко: модель пересчитывает траекторию, скорость, силы и радиусы.
- Вид сверху: след в масштабе — «щётки» плуга и тонкие линии канта, склон вниз по странице.
- Силы в каждый момент: поперечная и тормозная сила на каждой лыже, нагрузка внешней и внутренней.
- Радиусы: в плуге — из баланса сил, на канте — R выреза × cos θ, средний за поворот.
- 3D-фигура в той же позе, графики по ходу поворота и зависимость от места смены.

Модель упрощённая: лыжник — точка на ровном склоне, нет рельефа и прогиба лыж,
проскальзывание на параллельных не тормозит. Значения по умолчанию ориентировочные.
Вся страница — один файл `index.html`, без сборки.
